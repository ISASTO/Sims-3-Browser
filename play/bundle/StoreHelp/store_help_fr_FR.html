Q : Comment les transactions que j'ai effectuées dans le jeu (achats/microtransactions intégrées à l'application) sont-elles facturées ?
R : Les achats vous sont facturés de la même manière que n'importe quel achat sur votre appareil : depuis votre compte iTunes. iTunes est une marque commerciale d'Apple Inc., enregistrée aux États-Unis et dans d'autres pays. Si vous avez des questions ou différends à soulever quant à la facturation, veuillez contacter Apple. Apple est une marque commerciale d'Apple Inc., enregistrée aux États-Unis et dans d'autres pays

Q : J'ai acheté du contenu dans le jeu, mais je ne le vois pas. Que s'est-il passé ?
R : Quittez afin de retourner au menu principal, puis entrez à nouveau dans le magasin Les Sims. Consultez le statut de l'élément acheté. Si l'élément n'est pas disponible, sélectionnez le bouton "Restaurer les achats" dans le jeu. L'élément acheté devrait devenir disponible.

Q : J'ai acheté du contenu sur mon iPhone. Puis-je y accéder depuis mon iPod/iPad (ou vice-versa) ? iPhone, iPod et iPad sont des marques commerciales d'Apple Inc., enregistrées aux États-Unis et dans d'autres pays.
R : Oui, à condition que ces appareils partagent le même compte iTunes. Tout d'abord, lancez le jeu sur l'appareil sur lequel vous voulez avoir le nouveau contenu (si vous n'avez pas encore le jeu sur cet appareil, allez dans la boutique iTunes et téléchargez-le). Allez ensuite dans le magasin Les Sims et sélectionnez le bouton "Restaurer les achats" dans le jeu. Tous les éléments précédemment achetés devraient devenir disponibles.

Q : Je ne trouve pas de réponse à ma question ici. Que puis-je faire ?
R : Vous pouvez consulter les rubriques FAQ à l'adresse https://support.apple.com/itunes et contacter Apple pour tout problème de facturation. Vous pouvez aussi vous rendre sur https://help.ea.com et nous écrire. Lorsque vous nous contactez, pensez à nous fournir autant d'informations spécifiques que possible pour faciliter votre prise en charge.
